# Regras do projeto cAssistAI

- **Registro obrigatório:** toda alteração no app, decisão do proprietário, problema encontrado, teste feito ou mudança de situação (instalação, servidor, contas, integrações) deve ser registrada em `PROJETO_cAssistAI.md`, na seção "Registro de alterações", da mais recente para a mais antiga, no mesmo commit da alteração. Diga o que foi verificado e o que não foi.
- Mantenha atualizada a seção "Situação atual e próximos passos" do mesmo arquivo.
- Escreva para o proprietário em português simples e curto.
- Nunca coloque senhas, chaves (Groq, Google), códigos de instalação ou dados de clientes no repositório.
- Antes de enviar: `npm test`, `npm run build` e, quando mexer na tela, os testes de navegador.
